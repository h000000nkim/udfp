    HWP 미지원 기능 목록¶

    조사 기준: HWP 5.x 공식 스펙(rev 1.3), 한컴 공식 도움말(help.hancom.com), 오픈소스 파서 교차 분석

    조사 대상 코드: udf/parsers/hwp/, udf/renderers/hwp/, udf/schema/

    작성일: 2026-05-30

    범례¶

    상태 의미
    미지원 파싱·모델링 없음, 관련 데이터 무시됨
    부분 지원 파싱은 되나 일부 속성 누락 또는 생성 불가
    Verbatim 보존 원본 바이트 보존만 (의미 해석 없음, 동일 포맷 라운드트립은 가능)
    스키마만 존재 Document Model에 타입이 있으나 HWP 파서 미연결

    1. 컨트롤(ctrl_id) 단위 미지원¶

    1.1 완전 미지원 컨트롤¶

    ctrl_id 이름 설명 상태
    'tcmt' 메모/숨은 설명 본문에 연결된 메모. CommentBlock 스키마 있음 스키마만 존재
    'tdut' 덧말 (Ruby) 글자 위/아래 보조 텍스트 (한자 독음 등). RubyInline 스키마 있음 스키마만 존재
    'form' 양식 개체 텍스트입력/라디오/체크박스/콤보박스/리스트박스/버튼 (tag=95) 미지원
    'idxm' 색인 마크 색인 항목 등록 (주항목/부항목/페이지범위) 미지원
    'pgct' 홀짝수 쪽 번호 조정 홀수/짝수 쪽 번호 보정 미지원

    1.2 Verbatim 보존만 되는 컨트롤 (skip 리스트)¶

    ctrl_id 이름 설명 비고
    'bokm' 책갈피 하이퍼링크/상호참조/목차의 점프 대상. BookmarkBlock 스키마 있음 스키마만 존재
    'secd' 구역 정의 구역별 용지/여백/단/머리글/꼬리글 설정 (PAGE_DEF, FOOTNOTE_SHAPE, PAGE_BORDER_FILL 포함) Verbatim 보존
    'cold' 단 정의 다단 레이아웃 (단 수, 간격, 구분선, 균등배분) Verbatim 보존
    'nwno' 새 번호 지정 특정 위치부터 번호 다시 시작 Verbatim 보존
    'pghd' 페이지 감추기 쪽 번호 숨김 처리 Verbatim 보존
    'tcps' 글자 겹침 두 글자를 겹쳐 도장처럼 표시 Verbatim 보존
    '%bmk' 책갈피 범위 책갈피 시작/끝 마커 Verbatim 보존

    1.3 미지원 필드 컨트롤 (% 접두사)¶

    현재 %hlk(하이퍼링크)만 파싱. 나머지 전부 미지원:

    ctrl_id 이름 설명
    '%dt ' 날짜 현재 날짜 자동 삽입
    '%tm ' 시간 현재 시간 자동 삽입
    '%mf ' 파일 이름/경로 현재 파일 정보
    '%ti ' 제목 문서 제목
    '%su ' 주제 문서 주제
    '%au ' 작성자 문서 작성자
    '%fn ' 각주 번호 각주 참조 번호
    '%en ' 미주 번호 미주 참조 번호
    '%cc ' 누름틀 (ClickHere) 양식 입력 필드 (정부/기업 양식에 빈번 사용)
    '%ga ' 그림 번호 그림 캡션 자동 번호
    '%ta ' 표 번호 표 캡션 자동 번호
    '%eq ' 수식 번호 수식 캡션 자동 번호
    '%tc ' 목차 목차 자동 생성 필드
    '%ix ' 색인 색인 생성 필드
    '%xr ' 상호 참조 각주/미주/그림/표/수식/책갈피 번호 자동 참조
    '%bt ' 책갈피 텍스트 책갈피 위치 텍스트
    '%si ' 문서 요약 정보 문서 메타데이터
    '%kw ' 키워드 문서 키워드
    '%wp ' 글자수 문서 글자수
    '%ai ' 작성일 문서 작성일
    '%mi ' 최종 수정일 문서 최종 수정일
    '%me ' 메모 메모 필드
    '%hd ' 머리말 텍스트 머리말 참조
    '%ft ' 꼬리말 텍스트 꼬리말 참조
    '%ms ' 메모 요약 메모 요약
    '%pR ' 전체 쪽수 문서 전체 페이지 수

    3. 글자 모양 (CharShape) 누락 속성¶

    현재 파싱: bold, italic, underline(기본), strikeout(기본), 색상 5종, 크기, 자간, 장평, 위치, 위/아래첨자, emboss, engrave, outline(기본), shadow(기본), border_fill_id

    누락 속성 설명 스펙 위치
    강조점 종류 글자 위 점 표시 종류 (점/원/쉼표/사성점 등) CharShape attr bits
    외곽선 세분화 실선/점선/굵은선/파선/일점쇄선/이점쇄선 6종 CharShape attr bits 8-10
    그림자 세분화 비연속/연속 유형 + X/Y 오프셋 CharShape shadowGap[2]
    밑줄 세분화 둥근선/직선 형태, 6+종 (점선/파선/물결/이중/굵은/굵은파선) CharShape underlineShape
    취소선 세분화 점선/물결/이중 등 종류 CharShape strikeOutType
    커닝 플래그 영문 글자 간격 자동 조정 CharShape attr bit
    useFontSpace 글꼴 자간 사용 여부 CharShape field
    빈칸 폭 본래 폭 / 글자 크기의 1/2 CharShape 확장 속성
    숨김 텍스트 화면 표시만, 인쇄 제외 CharShape attr bit
    작은 대문자 (SmallCaps) 소문자를 작은 대문자로 CharShape attr bit
    글자 테두리 종류 (borderType) 글자 단위 테두리 종류 CharShape field
    형광펜 (Highlight) CharShape 배경과 별도인 형광펜 색상 별도 속성
    글자 회전 세로쓰기 등에서 개별 글자 회전 CharShape 확장

    4. 문단 모양 (ParaShape) 누락 속성¶

    현재 파싱: 정렬, 줄간격(타입+값), 왼쪽/오른쪽 여백, 첫줄 들여쓰기, 문단 위/아래 간격, protect, start_new_page, with_next_paragraph, tab_def_id, numbering_id, border_fill_id, outline_level

    누락 속성 설명 스펙 위치
    한글 줄나눔 기준 글자 단위 / 어절 단위 attr bit, breakNonLatinWord
    영어 줄나눔 기준 글자 / 어절 / 하이픈 attr bit, breakLatinWord
    자동 하이픈 연결 영문 하이픈 자동 삽입 attr bit, breakHyphenation
    드롭캡 단락 첫 글자 확대 (줄 수, 거리) ParaShape dropCapLines, dropCapDistance
    텍스트 방향 세로/가로 쓰기 방향 ParaShape textDirection
    글꼴 기준 줄 높이 글꼴 메트릭 기반 줄 높이 ParaShape fontLineHeight
    자동 간격 타입 CJK/Latin 혼합 시 자동 간격 ParaShape autoSpacingType (attr bits 20-22)
    테두리 타입 문단 테두리 적용 방식 ParaShape borderType (attr bits 16-19)

    5. 테두리/배경 (BorderFill) 누락 속성¶

    현재 파싱: 4변 테두리 (종류/두께/색상), 단색 채움

    누락 속성 설명 스펙 위치
    대각선 테두리 좌상→우하, 우상→좌하 각각 독립, 5가지 선 종류 BorderFill 대각선 6바이트
    그라데이션 채움 선형/원형/원뿔/사각형, 시작/끝 색상, 각도, 단계 BorderFill fill_type bit
    이미지 채움 늘이기/바둑판/가운데/실제크기, 이미지 ID BorderFill fill_type bit
    무늬 채움 무늬 종류, 전경/배경 색 BorderFill fill_type bit
    투명도 채움 투명도 (0~100%) BorderFill alpha 필드
    테두리 3D 효과 입체 테두리 BorderFill 확장
    테두리 그림자 테두리에 그림자 BorderFill 확장

    6. 표 (Table) 누락 속성¶

    현재 파싱: 행/열 수, 셀병합(colspan/rowspan), 셀 크기, 셀 패딩, 셀 수직정렬, 셀 테두리/배경, 반복헤더(attr bit)

    누락 속성 설명 스펙 위치
    셀 대각선 셀 내 대각선 (좌상→우하, 우상→좌하 독립) CELL_BORDER_FILL diagonal 필드
    셀 보호 편집 불가 셀 LIST_HEADER attr bit
    캡션 표 제목 (위치, 자동 번호, 텍스트) 별도 캡션 서브레코드
    제목줄 반복 페이지 넘김 시 첫 행 자동 반복 TABLE attr bit (파싱되나 모델에 미반영)
    쪽 넘김 허용 행 단위 페이지 분리 여부 TABLE attr bit
    계산식 셀 참조 수식 (SUM, AVG 등) 셀 필드
    자동 채우기 연속 데이터 자동 입력 표 편집 기능
    블록 계산 합계/평균/곱 표 편집 기능
    셀 텍스트 줄바꿈 모드 자동 줄바꿈 여부 LIST_HEADER attr
    행 높이 자동 맞춤 내용에 따라 높이 자동 조절 TABLE attr
    표 레이아웃 모드 고정/자동 레이아웃 TABLE attr

    7. 이미지/그림 (Image) 누락 속성¶

    현재 파싱: src(BinData 참조), crop(L/R/T/B), brightness, contrast

    누락 속성 설명 스펙 위치
    회전 각도 자유 회전 (0~360도) SHAPE_COMPONENT 회전 필드
    투명 색상 처리 특정 색상을 투명으로 (chroma key) 그림 속성
    그레이스케일/흑백 이미지 색상 모드 변환 그림 속성
    워터마크 모드 흐리게 표시 그림 속성
    채도 조절 이미지 채도 그림 속성
    반사 효과 거리, 크기, 투명도 그림 효과
    네온/발광 효과 색상, 크기 그림 효과
    그림자 효과 종류, 색상, X/Y 오프셋, 투명도 그림 효과
    좌우/상하 뒤집기 수평/수직 반전 SHAPE_COMPONENT 변환 필드

    8. 그리기 개체 (GSO/Drawing) 누락 속성¶

    현재 파싱: 위치(x,y), 크기(w,h), shape_type, fill_color, line_color, line_width, z_order

    누락 속성 설명 스펙 위치
    회전 각도 개체 회전 SHAPE_COMPONENT rotation 필드
    화살표 속성 선 시작/끝 화살표 형태, 크기, 채움 SHAPE_COMPONENT_LINE
    선 캡/조인 스타일 끝모양(둥근/각진/평평), 연결점 SHAPE_COMPONENT line 속성
    선 대시 패턴 점선/파선/혼합 등 세부 패턴 SHAPE_COMPONENT line 속성
    그림자 종류, 색상, X/Y 오프셋, 투명도 SHAPE_COMPONENT shadowInfo
    반사 효과 거리, 크기, 투명도 SHAPE_COMPONENT effect
    네온/발광 효과 색상, 크기 SHAPE_COMPONENT effect
    3D 효과 회전, 깊이, 조명 SHAPE_COMPONENT 3D
    그룹 계층 그룹 개체 내 부모-자식 계층 구조 GSO 그룹 container
    잠금 여부 위치/크기 잠금 SHAPE_COMPONENT attr
    세밀 배치 기준 쪽/단/문단/셀 기준 좌표 세분화 CTRL_HEADER 배치 속성
    곡선 제어점 베지에 곡선 제어점 목록 SHAPE_COMPONENT_CURVE
    연결선 개체 간 연결선 (경유점 포함) GSO connector

    9. 글상자 (TextBox) 누락 속성¶

    현재 파싱: 내부 텍스트(단락 리스트), 위치, 크기, 테두리

    누락 속성 설명
    내부 다단 글상자 내 다단 설정
    세로쓰기 글상자 내 세로 방향 텍스트
    크기 자동 조정 내용에 맞게 높이 자동 조정
    글상자 연결 넘치는 텍스트를 다음 글상자로 연결
    안쪽 여백 글상자 내부 L/R/T/B 여백
    세로 정렬 내부 텍스트 위/가운데/아래 정렬

    10. 각주/미주 누락 속성¶

    현재 파싱: 본문 텍스트(단락 리스트), 참조 번호(ref_num)

    누락 속성 설명 스펙 위치
    번호 형식 아라비아/한글/영문대소/로마대소/원문자/사용자정의 FOOTNOTE_SHAPE
    구분선 유무, 길이, 선 종류, 두께, 위치 FOOTNOTE_SHAPE
    번호 표시 방식 상첨자/괄호 등 FOOTNOTE_SHAPE
    쪽마다 번호 다시 시작 쪽 단위 리셋 FOOTNOTE_SHAPE
    구역마다 번호 다시 시작 구역 단위 리셋 FOOTNOTE_SHAPE
    각주 위치 쪽 아래 / 본문 아래 FOOTNOTE_SHAPE
    미주 위치 문서 끝 / 장 끝 FOOTNOTE_SHAPE

    11. 머리말/꼬리말 누락 속성¶

    12. 번호 매기기 (Numbering/Bullet) 누락 속성¶

    24. From Scratch 생성 불가 블록¶

    Seed Patch 모드에서는 원본 보존으로 우회 가능하나, From Scratch에서는 생성 자체가 불가:

    블록 타입 사유
    ChartBlock 차트 바이너리 데이터 생성 불가
    TextArtBlock 글맵시 렌더링 데이터 생성 불가
    DrawingBlock 도형 바이너리 생성 미구현 (파서만 있음)
    BookmarkBlock 책갈피 ctrl_id 생성 미구현
    CommentBlock 메모 ctrl_id 생성 미구현
    HeaderBlock 머리말 생성 미구현 (파싱만 가능)
    FooterBlock 꼬리말 생성 미구현 (파싱만 가능)
