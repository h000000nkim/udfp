# 외부 라이브러리 알고리즘 조사 워크플로

UDFP는 의존성을 최소화하고 외부 라이브러리의 알고리즘을 참조하여 자체 구현하는 방식을 채택. 이 스킬은 새 라이브러리를 조사하거나 기존 매핑을 갱신할 때 사용.

## 조사 절차

### 1단계: 메타정보 확인

- 라이브러리 명칭, 버전, GitHub URL
- **라이선스** (가장 중요. AGPL/GPL이면 코드 직접 인용 금지)
- 마지막 업데이트, 활동 수준
- 언어 (Python / Rust / JS / Java / C++)

### 2단계: 핵심 자료구조 식별

- 주요 데이터 클래스/구조체
- 필드와 타입
- 클래스 간 관계

### 3단계: 핵심 함수 시그니처 추출

- 진입점, 추출 함수, 변환 함수, 작성 함수
- 시그니처 + 입출력 타입 + 부수 효과

### 4단계: 알고리즘 핵심 원리 정리

함수 본문을 그대로 옮기지 말고 자연어로 요약:

```
PyMuPDF의 텍스트 추출:
- 페이지 콘텐츠 스트림 토큰화
- BT/ET 사이의 Tj, TJ 등 텍스트 연산자 추출
- CMap을 통해 글리프 ID → 유니코드
- 좌표 행렬 누적 → 글리프 절대 위치
- 좌표 클러스터링 → 단어/줄/문단 그룹화
```

### 5단계: UDFP 활용 방안 결정

- **의존성 직접 사용 가능** (MIT/BSD/Apache)
- **알고리즘 참조 + 자체 구현** (GPL/AGPL)
- **자료구조만 참조** (라이선스 무관)
- **Rust 가속 후보** (M11 PyO3 교체)

### 6단계: 매핑 표 갱신

`docs/library-mapping.md`에 추가:

```markdown
### <라이브러리명>
- 언어: ...
- 라이선스: ...
- URL: ...
- 마지막 업데이트: ...
- 핵심 자료구조: ...
- 핵심 함수: ...
- 알고리즘 요점: ...
- UDFP 활용: 의존성 / 알고리즘 참조 / 자료구조 참조
- 참조 시 주의사항: ...
```

## 조사 시 주의

- README만 보고 갱신 금지. 실제 소스 확인.
- 함수 본문 그대로 인용 금지 (라이선스 + 매핑 부풀림)
- 동일 기능 여러 라이브러리는 비교 표 작성
- 라이선스 "(확인 필요)" 항목 우선 해결
