    UdfDocument¶

    The central class for document manipulation.

    udf.pipeline.document.UdfDocument ¶

    UdfDocument(path_or_data: Any = None, /, **kwargs: Any)

    Bases: BaseModel

    Central API for manipulating documents in Universal Document Format.

    UdfDocument wraps a format-agnostic DocumentSchema (Document Model) and provides high-level operations for block/inline CRUD, text search/replace, table manipulation, and rendering to various output formats.

    It can be constructed from a file path (auto-detecting format), a dict, or keyword arguments. Lossless same-format roundtrips are supported via the verbatim layer; cross-format conversions carry a LossReport.

    ATTRIBUTE DESCRIPTION
    udf

    Schema version identifier.

    TYPE: str

    source_format

    Original format of the parsed document (e.g. "hwp", "docx", "pdf").

    TYPE: str

    document

    The format-agnostic document content (blocks, metadata, page boundaries).

    TYPE: DocumentSchema

    verbatim

    Raw byte preservation layer for lossless same-format roundtrip.

    TYPE: VerbatimLayer or None

    original_container

    Original file backup for Seed Patch mode generation.

    TYPE: OriginalContainer or None

    conversion_trace

    Parsing history and provenance.

    TYPE: ConversionTrace or None

    loss_report

    Report of information lost during conversion.

    TYPE: LossReport or None

    extensions

    Format-specific properties (e.g. HWP emboss, DOCX tracked changes).

    TYPE: dict[str, FormatExtension]

    outline

    Document outline / table of contents structure.

    TYPE: list[OutlineItem]

    Create a UdfDocument from a file path, dict, or keyword arguments.

    PARAMETER DESCRIPTION
    path_or_data

    If a string/Path, the file is parsed using the auto-detected format. If a dict, it is used as model data. If None, keyword args are used.

    TYPE: str, Path, or dict DEFAULT: None

    **kwargs

    Keyword arguments forwarded to the Pydantic model. May include blocks, metadata, source_format, etc.

    TYPE: Any DEFAULT: {}

    fill_template ¶

    fill_template(values: dict[str, str], *, delimiter: tuple[str, str] = ('{{', '}}'), strict: bool = False) -> dict[str, int]

    Replace template placeholders with values across all blocks.

    Searches for {{key}} patterns (or custom delimiters) in all text content and replaces them with the corresponding values. Works with Seed Patch mode for lossless form filling.

    PARAMETER DESCRIPTION
    values

    Mapping from placeholder names to replacement values. Example: {"이름": "김훈", "학번": "30217"}

    TYPE: dict[str, str]

    delimiter

    Opening and closing delimiter pair.

    TYPE: tuple[str, str] DEFAULT: ("{{", "}}")

    strict

    If True, raise ValueError when a placeholder in the document has no matching key in values.

    TYPE: bool DEFAULT: False

    RETURNS DESCRIPTION
    dict[str, int]

    Count of replacements per key. Keys with 0 replacements are included so callers can detect unused values.
    RAISES DESCRIPTION
    ValueError

    If strict is True and unmatched placeholders remain.

    set_placeholders ¶

    set_placeholders(placeholders: list[dict[str, Any]], *, delimiter: tuple[str, str] = ('{{', '}}')) -> list[dict[str, Any]]

    Mark specific text positions as template placeholders.

    Each placeholder replaces the text of a TextInline with {{key}}, preserving the inline's formatting (bold, font, color, etc.). The resulting placeholder can later be filled via :meth:fill_template.

    PARAMETER DESCRIPTION
    placeholders

    Each dict must contain:

    • block_id (str): target block ID. Must resolve to a ParagraphBlock or HeadingBlock (including those nested inside table cells, text boxes, footnotes, etc.).
    • inline_idx (int or None): index of the TextInline to replace. If None, a new TextInline is appended to the block's inlines list (useful for empty paragraphs).
    • key (str): placeholder name. Allowed characters: [a-zA-Z0-9_가-힣].

    TYPE: list of dict

    delimiter

    Opening and closing delimiter pair wrapping the key.

    TYPE: tuple[str, str] DEFAULT: ("{{", "}}")

    RETURNS DESCRIPTION
    list of dict

    One result per input, each containing key, block_id, inline_idx, previous_text, and placeholder.
    RAISES DESCRIPTION
    ValueError

    If any placeholder spec violates the placement rules. The error message names the exact rule that failed.

    Usage Examples¶

    Construction¶

    from udf import UdfDocument

doc = UdfDocument("path.hwp")           # parse from file
doc = UdfDocument.from_json(json_str)   # deserialize from JSON
doc = UdfDocument.from_dict(data)       # from dict
doc = UdfDocument.empty()               # blank document

    Text Operations¶

    doc.replace_text("old", "new")          # global find and replace
matches = doc.find_text(r"\d{4}-\d{2}") # regex search → list of (block_id, match)

    Template Fill¶

    Replace {{placeholder}} patterns across the entire document. Works with Seed Patch for lossless form filling.

    # HWP 양식에 {{이름}}, {{학번}} 등을 미리 입력해두고:
doc = udf.parse("template.hwp")
result = doc.fill_template({
    "이름": "김훈",
    "학번": "30217",
    "희망진로": "AI 엔지니어",
})
doc.to("hwp", "filled.hwp")  # Seed Patch → 양식 100% 보존

# 커스텀 delimiter
doc.fill_template({"name": "Kim"}, delimiter=("{%", "%}"))

# strict 모드: 미매칭 placeholder가 남으면 ValueError
doc.fill_template(values, strict=True)

    Block CRUD¶

    All block operations perform deep tree search (including inside table cells, text boxes, etc.).

    block = doc.get_block("b_0003")
paragraphs = doc.find_blocks("paragraph")

doc.add_block(new_block, after="b_0003")
doc.add_block(new_block, parent_id="cell_id")  # inside a container
doc.remove_block("b_0003")
doc.move_block("b_0003", after="b_0010")

    Inline Operations¶

    inline = doc.get_inline("b_0003", 0)
doc.set_inline_text("b_0003", 0, "new text")
doc.set_inline_format("b_0003", 0, bold=True, font_size=14.0)
doc.add_inline("b_0003", TextInline(type="text", text="added"))
doc.remove_inline("b_0003", 1)
doc.split_inline("b_0003", 0, offset=5)

    Table Operations¶

    cell = doc.get_cell("table_id", row=0, col=1)
doc.add_table_row("table_id", at=2)
doc.remove_table_row("table_id", 0)
doc.add_table_column("table_id", at=1)
doc.remove_table_column("table_id", 2)
doc.merge_cells("table_id", r1=0, c1=0, r2=1, c2=1)

    Table Layout Control¶

    Fix cell sizes to preserve form layouts when rendering.

    tbl = doc.tables[0]

# 래퍼 메서드 — 자주 쓰는 패턴
tbl.freeze_columns()           # 모든 열 너비 고정
tbl.freeze_rows([0, 1, 2])     # 특정 행 높이 고정
tbl.freeze_cell(0, 0)          # 특정 셀 너비+높이 고정
tbl.freeze_labels(label_col=0) # 레이블 열 너비+높이 고정

# 저수준 — 셀 단위 제어
cell = tbl.rows[0].cells[0]
cell.fixed_width = True        # 이 셀의 width를 최종 값으로 사용
cell.fixed_height = True       # 이 셀의 height를 고정

# layout_type으로 전체 제어
tbl.layout_type = "auto"       # 텍스트 기반 자동 크기 (기본은 freeze)

    기본 동작

    layout_type이 설정되지 않으면(None) 원본 셀 크기가 자동 보존됩니다. 텍스트 기반 자동 크기 조정이 필요하면 tbl.layout_type = "auto"로 명시하세요.

    Rendering¶

    md = doc.to("md")                          # render to string
doc.to("hwp", output_path="out.hwp")      # render to file
json_str = doc.to_json()                   # serialize to JSON
data = doc.to_dict()                       # serialize to dict
doc.save("out.udf.json")                   # save JSON file
