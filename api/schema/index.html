    Schema¶

    The udf.schema module defines all data types used in the Document Model.

    from udf.schema import ParagraphBlock, TextInline, BlockFormat, DocumentMetadata

    Document¶

    udf.schema.DocumentSchema ¶

    Bases: BaseModel

    The format-agnostic document content definition.

    Fully describes document structure and content without any conversion infrastructure (verbatim, original_container, etc.).

    Block Types¶

    All blocks inherit from BlockBase and have at minimum type: str and id: str fields.

    Structural Blocks¶

    udf.schema.ParagraphBlock ¶

    Bases: BlockBase

    A paragraph — the primary text-bearing block composed of inlines.

    udf.schema.HeadingBlock ¶

    Bases: BlockBase

    A heading (section title) with a hierarchical level.

    udf.schema.ListBlock ¶

    Bases: BlockBase

    An ordered or unordered list containing ListItems.

    udf.schema.TableBlock ¶

    Bases: BlockBase

    A table with rows, cells, optional captions, and border definitions.

    TableCell Layout Properties¶

    Property Type Default Description
    fixed_width bool False Fix this cell's width (skip auto-calculation)
    fixed_height bool False Fix this cell's height (skip auto-expansion)
    width float None Cell width in points
    height float None Cell height in points

    TableBlock Layout Methods¶

    Method Description
    freeze_columns() Fix all cell widths
    freeze_rows(indices) Fix specific (or all) row heights
    freeze_cell(row, col) Fix a specific cell's width and height
    freeze_labels(col=0) Fix label column width and height

    layout_type: None (default, freeze) / "fixed" (explicit freeze) / "auto" (text-based sizing)

    Content Blocks¶

    udf.schema.ImageBlock ¶

    Bases: BlockBase

    A block-level image with optional caption and positioning.

    udf.schema.CodeBlock ¶

    Bases: BlockBase

    A fenced code block with optional language annotation.

    udf.schema.EquationBlock ¶

    Bases: BlockBase

    A display-mode equation (LaTeX, HWP script, or MathML).

    udf.schema.QuoteBlock ¶

    Bases: BlockBase

    A block quotation containing nested blocks.

    Layout Blocks¶

    udf.schema.PageBreakBlock ¶

    Bases: BlockBase

    An explicit page break.

    udf.schema.HorizontalRuleBlock ¶

    Bases: BlockBase

    A horizontal rule (thematic break).

    udf.schema.TextBoxBlock ¶

    Bases: BlockBase

    A positioned text container (floating or anchored).

    udf.schema.DrawingBlock ¶

    Bases: BlockBase

    A vector drawing or shape object, possibly containing nested content.

    Document Parts¶

    udf.schema.HeaderBlock ¶

    Bases: BlockBase

    Page header content, scoped to all/odd/even/first pages.

    udf.schema.FooterBlock ¶

    Bases: BlockBase

    Page footer content, scoped to all/odd/even/first pages.

    udf.schema.FootnoteBlock ¶

    Bases: BlockBase

    A footnote definition referenced by FootnoteRefInline.

    udf.schema.EndnoteBlock ¶

    Bases: BlockBase

    An endnote definition referenced by EndnoteRefInline.

    Special Blocks¶

    udf.schema.BookmarkBlock ¶

    Bases: BlockBase

    A named bookmark for internal cross-references.

    udf.schema.CommentBlock ¶

    Bases: BlockBase

    A review comment (annotation) anchored to a range of content.

    udf.schema.FieldBlock ¶

    Bases: BlockBase

    A form field or dynamic field (text input, dropdown, checkbox, etc.).

    udf.schema.UnknownBlock ¶

    Bases: BlockBase

    A block the parser could not classify. Raw bytes are preserved for lossless roundtrip.

    Inline Types¶

    Inlines represent content runs within blocks (paragraphs, headings).

    udf.schema.TextInline ¶

    Bases: _Base

    A run of styled text within a paragraph.

    udf.schema.LinkInline ¶

    Bases: _Base

    A hyperlink with display text and target URL.

    udf.schema.ImageInline ¶

    Bases: _Base

    An inline image embedded within text flow.

    udf.schema.FootnoteRefInline ¶

    Bases: _Base

    An inline reference marker pointing to a FootnoteBlock.

    udf.schema.EndnoteRefInline ¶

    Bases: _Base

    An inline reference marker pointing to an EndnoteBlock.

    udf.schema.EquationInline ¶

    Bases: _Base

    An inline equation (LaTeX, HWP script, or MathML).

    udf.schema.RubyInline ¶

    Bases: _Base

    Ruby annotation — small text above/below base characters for pronunciation.

    udf.schema.CodeInline ¶

    Bases: _Base

    An inline code span.

    Formatting¶

    udf.schema.BlockFormat ¶

    Bases: _Base

    Paragraph-level formatting: font, alignment, spacing, indentation, borders.

    udf.schema.CellFormat ¶

    Bases: _Base

    Table cell formatting: background, borders, padding, alignment.

    Metadata¶

    udf.schema.DocumentMetadata ¶

    Bases: _Base

    Top-level document metadata: title, author, page layout, numbering config.

    udf.schema.PageMargins ¶

    Bases: _Base

    Page margin dimensions (top, bottom, left, right) in pt.

    Unit Converters¶

    All converters are available from udf.schema:

    from udf.schema import hwpunit_to_pt, pt_to_hwpunit, emu_to_pt, twip_to_pt, mm_to_pt
    Function Conversion Example
    hwpunit_to_pt(v) HWPUNIT → pt hwpunit_to_pt(1200) → 12.0
    pt_to_hwpunit(v) pt → HWPUNIT pt_to_hwpunit(12.0) → 1200
    emu_to_pt(v) EMU → pt emu_to_pt(914400) → 72.0
    pt_to_emu(v) pt → EMU
    twip_to_pt(v) Twip → pt twip_to_pt(240) → 12.0
    pt_to_twip(v) pt → Twip
    halfpt_to_pt(v) Half-point → pt halfpt_to_pt(24) → 12.0
    pt_to_halfpt(v) pt → Half-point
    mm_to_pt(v) mm → pt mm_to_pt(25.4) → 72.0
    pt_to_mm(v) pt → mm
    px_to_pt(v) px → pt px_to_pt(16) → 12.0
    pt_to_px(v) pt → px

    Types¶

    udf.schema.Color ¶

    Color(r: int, g: int, b: int, a: float = 1.0)

    Normalized RGBA color. Parsers convert any color representation to this type.

    Initialize an RGBA color.

    Parameters:

    Name Type Description Default
    r int

    Red channel (0--255).

    		 required
    g int

    Green channel (0--255).

    		 required
    b int

    Blue channel (0--255).

    		 required
    a float

    Alpha (opacity) from 0.0 (transparent) to 1.0 (opaque).

    		 1.0

    Ratio(percent: float)

    A percentage ratio value (e.g., line spacing 160%, character scale 85%).

    Initialize a ratio value.

    Parameters:

    Name Type Description Default
    percent float

    The ratio expressed as a percentage (e.g. 160.0 means 160%).

    		 required
